<p>第一类是纯代理地址，给你IP、端口、账号；第二类是住宅VPS，给你一台能登录的主机，地址挂在上面；第三类是专线加地址的组合。</p>
<p>三类价格差很大，用途也不同。纯地址适合浏览器场景，VPS适合要装软件的场景，专线适合对上行和稳定性有要求的场景。</p>
<p>先确认自己需要哪一类，再看报价。拿纯地址的价去比VPS的价，永远比不出结论。</p>
<h2>二、试用能验什么，不能验什么</h2>
<p>能验的是地址归属、延迟、丢包、认证是否顺畅、面板好不好用、客服响应速度。这些一两天就能看清。</p>
<p>不能验的是长期在线率、上游线路变更频率、高峰期表现。这些要跑满一个月才有数据。</p>
<h3>试用账号的常见限制</h3>
<p>限带宽、限时长、限并发是常态。试用跑得顺不代表正式一样，重点看的是流程是否规范、参数是否给全。</p>
<h2>三、100M专线这句话怎么读</h2>
<p>先问是共享还是独享。共享100M是一群人分，高峰期可能只剩几兆；独享100M才是真的给你一条。</p>
<p>再问单位与方向。100Mbps换算下来约十二兆字节每秒，上下行是否对称要单独确认，很多线路下行给足、上行减半。</p>
<p>最后问超量怎么办。有的按峰值计费，有的限速不断网，条款不同，长期成本差很多。</p>
<h3>共享100M和独享100M</h3>
<p>共享的报价常按峰值卖，实际分到多少看同一时间有多少人在跑；独享的价格高，但可预期。要合同写明承诺带宽。</p>
<h2>四、从试用到正式开通</h2>
<p>试用期结束前把参数表、测试记录、问题清单整理好，一次性提给服务商。问题问得具体，回答才具体。</p>
<p>正式开通后别急着铺开。先按试用的配置复制一份，跑三天确认一致，再批量上。</p>

<p>分批的意义在于把故障限制在小范围。一次全铺，出问题时连回退都难。</p>
<h2>五、平台选择的四个硬条件</h2>
<p>一看参数是否透明，端口协议加密方式写不写清；二看能否自助换IP；三看有没有用量与在线记录；四看故障时能不能找到人。</p>
<h3>面板要有什么</h3>
<p>至少要能看到地址列表、剩余流量、在线时长、最近变更记录。只有一张静态表格的面板，长期管理会很吃力。</p>
<p>面板还应当能导出记录。对账、排障、交接都要用，靠截图整理迟早出错。</p>
<h2>六、验收清单</h2>
<p>地址归属与ASN对得上、延迟与丢包在约定范围、认证一次通过、上行达到标称、面板数据可查。五项过完再谈长期。</p>
<p>专线类还要加一项：多IP是否各自独立可路由，别拿到手发现只有一个能出网。</p>
<p>价格方面，带专线的组合月费通常高于纯地址，区间跨度大，具体以平台报价为准，仅供参考。</p>
<h2>常见问答</h2>
<h3>试用期一般多长？</h3>
<p>答：常见一天到三天，也有按流量给少量额度的。够做基础核验，但不足以判断长期在线率。</p>
<h3>100M专线是独享带宽吗？</h3>
<p>答：不一定是。要单独确认是共享还是独享、上下行是否对称、超量如何计费，三项都写在订单里再付款。</p>
<h3>住宅VPS和普通VPS有什么不同？</h3>
<p>答：差别在出口地址的属性。普通VPS出口登记在机房名下，住宅VPS出口登记在居民宽带运营商名下，其余配置可以相近。</p>
<h3>平台便宜就一定差吗？</h3>
<p>答：不一定，但要看得清规格。价格低而参数模糊的，通常在某处省了成本，先小额试用再决定。</p>
